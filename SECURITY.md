# Security Policy

## Supported Versions
Only the latest code on the `main` branch is officially supported.

## Reporting a Vulnerability
If you discover a security vulnerability, please report it responsibly — do NOT disclose it publicly until we have addressed it.

📧 **Email: security@ezedigital.co.uk**

- You will receive an acknowledgement within **48 hours**.
- We will provide a timeline for resolution and keep you updated.
- We do not currently offer paid bug bounties — but ALL reports are taken seriously.
- Once fixed, we will publish a public disclosure with your credit if you wish.
