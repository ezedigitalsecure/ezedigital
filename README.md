# Eze Digital — Website & Academy Repository

## Overview
The Eze Digital repository is the official digital presence of **Eze Digital Ltd**, a UK‑based cybersecurity, compliance, and training organisation. We deliver accessible web design, end‑to‑end digital protection, and CPD‑accredited training — all crafted in plain English, built around your needs.

This repository powers both our core business site and the **Eze Digital Academy**, presenting our services, accredited courses, team, pricing, and student portal — with clear ways to engage, book, and learn.

## Why This Project Exists
This project was created to establish a unified, professional digital home for Eze Digital — one that reflects our dual mission: building secure, beautiful digital foundations *and* empowering people through accessible education.

The website provides a central platform where organisations and individuals can explore our cybersecurity services, CPD‑certified training programmes, brand & identity work, and compliance guidance. It also demonstrates modern standards in accessible frontend development, responsive design, modular architecture, and maintainable code — exactly the quality we deliver to clients.

## Architecture
The website uses a modular, component‑based architecture designed to keep the codebase organised, consistent, and easy to update across every page.

- **Shared components** — Single source for header, navigation, footer, and call‑to‑action elements so changes apply site‑wide
- **Reusable UI patterns** — Course cards, service blocks, pricing tables, and buttons with uniform styling
- **Logical separation** — Pages grouped by function so new content can be added without rebuilding the whole system
- **Consistent styling** — Central CSS variables for colours, typography, and spacing ensuring brand uniformity
